# 09 - 项目集成

## 接入边界

集成项目安装公开通信 SDK，在自己的服务中接入 Gateway、用户认证、业务上下文和工具处理器。Frogie 私有仓库维护角色、提示词、Skills、脚本和本机扩展；daemon 管理所有 Pi Harness、模型、SQLite、历史与恢复。

业务项目只使用 SDK 的结构化接口，最终产物按项目自身规则保存。Dashboard 和业务 UI 使用同一套执行投影，前者展示通用 Agent 结构，后者展示业务过程。协议与认证见 [通信 SDK](11-communication-sdk.md)，本地运行见 [本地 Daemon](10-local-daemon.md)。

## 项目需要提供的内容

| 内容 | 职责 |
| --- | --- |
| Gateway 路由 | 接收本机主动建立的 WSS，使用 SDK 实现认证、投递与状态查询 |
| 用户认证与授权 | 将业务登录映射成可信主体，限制项目、资源、动作与观察字段 |
| 上下文处理器 | 返回带资源身份、版本和摘要的最新业务资料 |
| 业务工具处理器 | 校验结构化输入、权限、审批及资源版本，执行并返回持久回执 |
| 投递存储 | 保存请求、取消、连接租约、去重与业务操作回执，复用现有业务数据库 |
| 业务 UI | 连接状态、聊天、任务进展、工具与产物的业务呈现 |
| 业务产物 | 保存文稿、音频、报告等最终结果，提供授权文件传输 |

项目自己的基本功能独立于 Gateway 在线状态。未连接时正常展示已有资料、编辑和管理业务数据；Agent 入口明确离线。可选排队必须有期限、取消入口和送达前授权。

## Frogie 需要提供的内容

在本机登记项目、Squad 与环境，选择模型、权限和执行预算，安装已批准的本机扩展。用户在 Dashboard 配对远端并核对两方向能力，Connector 主动发起连接。

远端工具的 schema、版本和准入由本机绑定管理。断线时本地会话和历史继续可用，远端能力返回明确不可用状态。业务配置每次按资源版本获取，本机保存实际用于执行的输入快照；生成结果先成为可追溯本地产物，业务写回以项目回执为准。

本机扩展在 `integrations/<project-id>/` 中使用 Pi 原生 Tool、Extension 与所有权机制，由 daemon 显式注册。需要本机算力或脚本的工作由受控执行器承载；云端处理器保留业务控制与存储，不接触本机通用命令执行入口。

## his.fm 接入

### 保留定义与业务行为

`squads/hisfm/` 中主控、writer、reviewer、speech 四个角色及完整十六项提示词继续由 Frogie 维护。正文、内容摘要与拼装顺序作为回归契约，配对和传输改造保持这些定义原意。

his.fm 保留频道、栏目、作品、逐字稿版本、人工审批和音频管理。栏目资料、目标听众、本次需求与作品版本通过上下文接口返回；角色定义和 Prompt 编辑由 Frogie 管理，网站业务配置作为输入资料，凭据通过相应服务的私有配置管理。

主控的派发、复用条件、reviewer 长期会话、writer 工作单元和 speech 任务关联由本机项目扩展落实，继续使用 Pi 原生会话与任务。网站执行资料读取、提案、作品修改、审核状态和产物存储。

本地阶段先完成 `integrations/hisfm/` 的工具分类：`reply`、`delegate`、`inspect_work`、`retire_conversation`、`submit_result` 和 `finish_command` 的会话与工作状态在本机持久维护。普通回复与纯本地任务交付以本地回执完成，有网站副作用的任务才要求相应业务保存回执。新输入、普通角色对话、历史总结和压缩使用本地执行意图与冻结 Prompt，独立于网站 command 或实时栏目读取。

`read_latest`、`list_productions`、提案、作品修改、审批提交和音频业务请求属于远端能力，未配对或断线时明确不可用。writer／reviewer 所需 `coding-tools` 在本地阶段通过受控 ExecutionEnv 和 OS 沙箱提供；真实研究按 [Dashboard](04-dashboard.md) 的获准网络出口执行，speech 的执行器与凭据在实际获准任务时使用。四类 Extension 的结构与本地行为先在无远端条件下完成预检和测试。

### 现有实现的调整位置

以下路径是现有接入的定位依据，具体文件划分在实现时按职责收敛：

| 位置 | 调整 |
| --- | --- |
| Frogie `packages/core/src/host/` | 执行与恢复作为 daemon 内部基础，保持原生 Pi 语义 |
| Frogie `packages/core/src/squads/`、`squads/hisfm/` | 定义留在 `squads/`，领域装配和本机扩展归入 `integrations/hisfm/`，由 daemon 加载 |
| `../his.fm/packages/agent/src/transport.ts` | 将出站连接、心跳、重连和可靠投递共性归入 Frogie Connector／SDK |
| `../his.fm/apps/web/worker/agent-hub.ts` | 接入 SDK 的 Cloudflare Gateway，保留业务路由与所需存储绑定 |
| `../his.fm/apps/web/worker/agent-runtime.ts` | 将现有登录与业务授权映射到 SDK 身份和配对流程 |
| his.fm 本地 Agent 宿主与 `vendor/` Core 包 | 切换为本机 daemon 后移除运行入口、Core tarball 和依赖 |
| his.fm 网站与共享契约 | 仅依赖 SDK，业务 schema 和状态机由项目自己维护 |

本地模型配置、执行记忆与语音执行从项目宿主收拢到 Frogie，业务凭据按明确用途授权。移交凭据只由用户确认的配置操作完成，日志和验收材料保持脱敏。

### 完整生产路径

1. 网站显示 Frogie 连接状态，拥有者从 his.fm 提交一次创作意图；本机 Dashboard 也能对相同项目发起获准工作。
2. Frogie 读取最新栏目、创作所需业务资料和作品版本，保存输入快照，由主控整理选题并派发研究及审阅。
3. 根据真实结果完善选题，通过业务工具保存提案或作品，his.fm 校验版本并返回回执；选题由拥有者确认。
4. writer 编写逐字稿，reviewer 审阅，主控根据反馈修订。网站保存结构化文稿和版本，拥有者确认最终逐字稿。
5. 获准的语音请求关联原请求与具体文稿版本；本机 speech 角色使用授权快照调用实际生成能力，音频通过 HTTPS 上传到项目存储。
6. his.fm 保存音频和作品状态，返回最终回执；Frogie 汇总必需子任务结果，原用户请求进入明确终态。网站可以播放真实音频，双方可追溯选题、文稿和音频的对应版本。

人工审批与公开发布由 his.fm 业务控制器和拥有者决定。本地产物、模型完成、等待审核与业务保存分别可见。异步语音任务必须关联回原用户请求，终态由真实业务回执确认。

### 断线、恢复与验收

远端断开时，网站基本功能保持可用，Frogie 继续本地聊天、历史总结与调试。旧上下文只作为带版本的历史材料；新远端读取和未接纳的写入返回不可用。已持久接纳的安全写入按原操作 ID 对账，结果不明确时先查询回执。

验收使用一个新的完整作品，经过真实网站入口、实际模型、人工确认与真实音频生成。记录匹配的 SDK、daemon、网站版本，保存 Conversation、Submission、Task、业务操作与作品版本的关联。模型替身的通过结果只用于机制测试。

重启后继续原会话，成功保存的结构化结果和音频保持原业务记录。his.fm 的源码、声明文件、生产依赖图和构建产物只使用 SDK，不包含 Core、Pi 或私有提示词包。完整证据组织见 [Evals](07-evals.md)。

## 后续业务接入

新项目交付自己的定义、schema、授权、处理器、UI 和代表性验收案例。新增协议能力先进入共享符合性测试；daemon、Pi 恢复与网络共性在 Frogie 维护，项目通过库版本升级取得更新。

## 切换与交付

切换顺序遵循 [MVP 实施](08-mvp-implementation.md)：本机闭环、SDK 符合性与打包验证、发布、his.fm。集成项目安装确切 npm 版本并提交锁文件，通过库引用获取公共能力。

旧 Agent 工作先停止接纳并完成或显式取消，业务记录与原本地历史保留原样。新 daemon 从最新业务资料开始新的本地执行历史；历史数据转换或删除另行确认。目标接入使用唯一的新执行路径，验证通过后移除旧宿主及 tarball 入口。
